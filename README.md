# Business OS — Windows POS updates

This repository is the public download channel for the **Business OS POS** desktop application on Windows.

- Windows installer files and update metadata are published under [Releases](../../releases).
- The application's source code, private business data, API credentials, certificates, and database backups are **not** stored in this repository.
- Each Windows update release must include the installer `.exe`, `latest.yml`, and the corresponding `.blockmap` file if generated.
- The MacBook version is only an unsigned test build; it does not auto-update.

**Status:** A first Windows installer release has not yet been published. Automatic application updates will work only after an initial Windows release has been installed and a subsequent higher version is published and tested.
